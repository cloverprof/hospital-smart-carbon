# 演示脚本（DEMO_SCRIPT）

演示前准备：浏览器打开系统 → 登录页；如需干净状态，顶栏"更多 → 重置演示"（二次确认）。
三条主线各 5-8 分钟，可独立演示。数据基准日 2026-08-04。

## 主线 A：院领导决策（发现 → 归因 → 决策 → 回看）

1. 登录页点 **领导舱演示**（自动以院领导角色进入，权限开关关闭）。
2. 看顶部 7 项 KPI：年度碳排放同比为正、碳预算消耗快于时间进度 → "增速高于业务量增速"的信号。
3. 左列"风险与预警"：预算缺口风险标签 + 异常楼宇数；AI 建议指向手术医技楼。
4. 点击场景中 **手术医技楼** 红色名牌 → 弹窗显示本月/年度碳排、强度、同比，及"过去 31 日日碳排折线"——7 月 18 日后夜间基荷抬升可见；影响因素一句话指向净化空调 setback。
5. 顶栏进入 **AI 智能分析**：异常时间线找到 AN-001，展开看证据链（夜间功率 +24%、控制器计划表为空、无夜间加台）与置信度 92%。
6. 顶栏进入 **后勤运维 → 项目库管理**，打开 **减排方案计算器**：输入基线 758 MWh、节能率 24%、投资 68 万 → 实时得到年节省 ~13 万、年减碳 ~110 t、回收期 ~5 年；切换第二方案对比。
7. 点 **生成项目** → toast 显示新项目 ID；项目列表出现该项目（携带计算参数）。
8. 回到 **领导舱**：右列"减排投资 ROI"气泡图新项目在列；"路径" Tab 查看 2024-2030 减排路径与年度目标完成率。

## 主线 B：后勤闭环（告警 → 工单 → 处置 → 复测 → 关闭）

1. 登录页点 **后勤舱演示**（后勤负责人角色）。
2. 四 KPI：实时总负荷（5 秒模拟刷新）、今日综合碳排、保障系统在线率、待处理告警。
3. 点击 **手术医技楼** 名牌 → 弹窗列出当前故障：AHU-03 未进入 setback（严重）+ 备用汇流排异常（保障优先），显示估算额外碳排 kg/日、责任人、工单号 WO-2026-0712、处置状态与预计完成时间。
4. 顶栏 **后勤运维 → 设备台账与工单联动**：工单看板找到 WO-2026-0712（处理中列）。
5. 点开工单详情看处置日志时间线 → 按状态机推进：处理中 → 复测（填写备注"恢复 setback 计划并复测夜间功率"）。
6. 尝试非法流转（如直接关闭）→ 系统拒绝并提示，说明状态机约束。
7. 复测 → 复核 → 关闭；刷新页面，状态保留（localStorage 持久化）。
8. 回 **后勤舱**：待处理告警数下降；今日减碳任务"手术中心空调策略"进度可讲解为处置成果。

## 主线 C：核算与合规（数据质量 → 核算 → 锁定 → 报告 → 凭证）

1. 登录页点 **PC端演示**（能源管理员角色，全部权限开）→ 功能门户。
2. 进入 **碳管理 → 碳核算工作台**：五步流程条。第 3 步"质量校验"显示行政楼电表通讯中断造成的缺失（AN-008），完整率 97.8%。
3. 尝试第 4 步 **锁定批次** → 被数据质量阻止。
4. 在活动数据表对缺失区间执行 **补录/标记估算值** → 重新 **一键试算** → 完整率恢复。
5. 查看排放因子面板：电力 0.6096（2023 年公告，已核验，含来源链接）；天然气/热力标"待标准确认（演示）"。
6. **锁定批次**（二次确认）→ 表格只读；导出 CSV 报告（带 Demo 水印说明）。
7. 进入 **碳管理 → 合规凭证看板**：上传演示（拖拽任意文件，只留元数据）生成新版本；能源审计报告"即将到期"预警（2026-09-15，倒计时），对应领导舱履约里程碑同一事项。

## 附加演示点（穿插）

- 顶栏 **角色切换**：切到科室负责人 → 侧栏与门户模块可见范围收窄；打开 **全部权限** 恢复全量（两控件独立）。
- **用能日历**：点 7 月中下旬异常偏高日 → 当日业务量与告警联动解释。
- **医用气体管理**：备用汇流排异常置顶（保障优先级高于节能）；N2O GWP 三版本对照。
- **prefers-reduced-motion**：系统设置开启减少动态后动画停止。
- **断网演示**：`pnpm build && pnpm preview` 后断开外网，全部功能可用（无外部依赖）。
