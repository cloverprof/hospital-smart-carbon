## 3. 碳核算口径

- 边界：JS/T 303-2026《公共机构碳排放核算指南》口径 —— Scope1 = 天然气燃烧；Scope2 = 外购电力 + 外购热力。用水与医用气体不入合规总量（扩展边界单独演示）。
- 因子（见 src/data/factors.ts 与 docs/compliance-sources.md）：电力 0.6096 kgCO2/kWh（2023 年公告，已核验）；天然气 2.162 kgCO2/m³（演示缺省，待核验）；热力 110 kgCO2/GJ（演示缺省，待核验）。
- 公式：`楼宇日碳排(kg) = 电(kWh)×0.6096 + 气(m³)×2.162 + 热(GJ)×110`；全院 = Σ楼宇；月度 = Σ日度。
- 全站唯一因子来源为 `src/data/factors.ts` 的 `activeFactors`，页面禁止硬编码因子数值；项目种子 `calcParams.factor` 与派生的年减碳/回收期由同一因子推出，保证计算器结果与项目卡片一致。

## 4. 时序数据范围与粒度

| 序列 | 范围 | 粒度 | 生成函数 |
|---|---|---|---|
| 月度历史 | 2024-01 至 2026-08（8 月截至基准日） | 月 | monthlySeries / monthlyCarbonSeries |
| 日度历史 | 基准日前 14 个月起 | 日 | dailySeries / dailyCarbonSeries |
| 小时数据 | 任意日期按需生成（演示重点近 90 天） | 时 | hourlySeries |
| “实时” | 基准日 24h + 5 秒确定性抖动 | 5s | realtimePowerKw |
| 预测 | 2026-08-05 至 2026-09-30 | 日 | forecastDailyCarbon |
| 长期路径 | 2027-2030（仅领导舱情景） | 年 | 领导舱 path 计算 |

生成模型：`用量 = 基准日耗 × 季节因子(合成气温) × 业务因子(门诊/手术/床位) × 异常链因子 × ±4% 噪声`。业务量本身也是确定性序列（工作日/周末/季节/年增长）。

## 5. 业务量指标

| 指标 | 函数 | 量级 |
|---|---|---|
| 门诊人次/日 | outpatientVisits | 工作日约 8,200，周末约 45% |
| 手术台次/日 | surgeryCount | 工作日约 96 |
| 床位使用率 % | bedOccupancy | 约 88%±5 |

派生指标：床日能耗 = 品种用量 ÷ (床位×使用率)；门诊人次能耗 = 门诊区能耗(分摊 42%) ÷ 门诊人次。

## 7. 状态机

- 告警：待处理 → 处理中 ⇄ 已确认 → 已解决（终态）
- 工单：接收 → 判断 → 已指派 → 处理中 → 复测 ⇄（不合格退回处理中）→ 复核 → 已关闭（终态）
- 项目：立项 → 设计 → 施工 → 验收 → 运行（终态）

定义：src/services/machines.ts；单元测试锁定合法/非法流转。

## 8. 计算器公式

见 src/services/calculator.ts（UI 内"公式与假设"面板同步展示）：年节能量 = 基线×节能率；年节省 = 节能量×单价−运维；年减碳 = 节能量×因子；回收期 = 投资÷年净节省（净节省≤0 → 不可回收）；NPV = −投资 + Σ净节省/(1+r)^t。输入钳制防除零/NaN/负回收期，测试覆盖零值/边界/单位换算。

## 9. 持久化

命名空间 `hospital-carbon-demo:v1:*`（schema v1）。持久化内容：角色、全部权限、场景模式、院区、各页筛选、最近访问、告警/工单/项目运行时状态、各模块自建 store（核算批次、凭证、巡检任务等）。重置演示：仅删本命名空间 key 后恢复种子数据。
