# 关键决策与假设记录

记录日期：2026-08-04。每条含：决策、原因、影响范围。

## 架构

1. **路由采用 HashRouter**。原因：提示词 10.4 要求静态交付优先不依赖服务器 rewrite；Hash 路由在根路径、子目录、内网静态服务器均可直接刷新深链接。影响：所有内部链接为 `#/...` 形式；不需要 SPA fallback 配置。
2. **Vite `base` 默认 `"./"`（相对路径），可用环境变量 `VITE_BASE_PATH` 覆盖**。原因：相对路径同时满足根路径与任意子目录部署。影响：见 README 部署一节。
3. **保留旧版三个碳管理页面的数据与逻辑作为参考，新信息架构下重写 UI**。原因：旧页面绑定旧壳层 CSS 与旧路由；新 IA 有统一组件库与权限体系。旧文件保留在仓库中（不再挂路由）。
4. **新增依赖仅 vitest（devDependency）**。原因：提示词 14 要求计算器与状态机单元测试；运行时依赖零新增。

## 数据

5. **确定性数据引擎**：所有时序由 `mulberry32(hashSeed(key))` 生成，key 含楼宇/品种/日期。原因：提示词 7.3 禁止渲染间数值跳变；同参必同值使"总量=分项和"可测试。影响：`src/services/timeseries.ts` 是全站唯一数据来源，页面禁止自造随机数。
6. **月度 = 日度之和、全院 = 楼宇之和（按构造成立）**，由单元测试锁定（`src/services/__tests__/timeseries.test.ts`）。
7. **演示基准日集中于 `demoAsOfDate = "2026-08-04"`**（`src/data/config.ts`），改一处全站平移。
8. **电力排放因子取 0.6096 kgCO2/kWh**（2023 年全国电力平均，不含市场化交易非化石口径，生态环境部 2025-12-31 公告）。原因：核算年 2026 应使用最新已发布年份因子；医院未采购绿电。影响：全站碳排数值；因子切换入口保留在碳核算工作台。
9. **年度内部碳预算 52,000 tCO2e**：设定为略低于按当前强度推算的年排放，使"预算缺口风险"演示链路可见。标注"内部碳预算/情景模拟"（医院未纳入强制碳市场，已核验）。
10. **门诊人次碳排分摊 42%**：门诊综合楼+检验+影像占比的演示分摊口径，写入数据字典；非核算标准。

## 场景与 3D

11. **楼宇名牌锚点为配置化百分比坐标**（`src/data/buildings.ts` `anchor` 字段），基于对夜景渲染图的目视判断映射，**映射假设**：
    - 前景大曲面连体裙楼 = 门诊综合楼；后排双塔 = 住院部 A/B 楼；中部连廊建筑 = 手术医技楼；带停机坪建筑 = 急诊中心；左前低层带停车场 = 后勤动力中心；其余按方位近似分配。
    - 模型无楼宇命名信息，以上映射不代表真实设计意图；调整只需改 `anchor` 一处。
12. **3D 环绕方案暂缺，交付静态夜景 + 完整交互**。原因见 `IMPLEMENTATION_GAPS.md`（.max 无合法转换路径，非浏览器硬限制，不伪造完成）。顶栏显示禁用态开关与说明 tooltip；`SceneStage` 组件保留 sceneMode 架构，未来提供 GLB 后可挂载。

## 权限与持久化

13. **四角色 × 模块可见性/可写性集中在 `src/data/navigation.ts`**（visibleModules/canWrite），页面禁止散落角色字符串判断。前端 Demo 权限，不替代服务端鉴权（界面已注明）。
14. **localStorage 命名空间 `hospital-carbon-demo:v1:*`**，schema version=1；版本不符直接丢弃回种子数据（最小迁移策略）。重置演示只删除本命名空间 key，绝不 `localStorage.clear()`。
15. **登录页三入口默认角色**：领导舱演示→院领导（全部权限关）；后勤舱演示→后勤负责人（关）；PC端演示→能源管理员（开）。依据提示词 5.3。

## 界面

16. **驾驶舱目标高度 ≥1080px**；低于目标高度时 HUD 列内出现细滚动条（开发窗口降级），1080/1440 下无滚动。
17. **图表统一走 `EChart` 包装**（暗色主题、tooltip、失焦暂停、实例清理）；导出库（xlsx/jszip）按需动态 import。
18. **lucide-react 图标具名导入**；壳层导航因需按字符串渲染任意图标使用命名空间导入（体积代价已接受，见 performance-report.md）。
